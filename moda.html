Modern Data Architecture

데이터 처리 도구와 데이터베이스 연결부터 파이프라인 구성, 실행 일정, 작업 이력 확인까지 한곳에서 관리하는 데이터 운영 웹 애플리케이션입니다.

Back to portfolio

Project overview

MODA(Modern Data Architecture)는 서로 다른 화면과 도구에서 관리하던 데이터 운영 작업을 하나의 UI로 연결하기 위해 만든 프로젝트입니다. 도구 설치 및 상태 확인, Source/Target DB 연결 테스트, 이관·변환 작업 정의, 스케줄 등록과 실행 결과 확인까지 데이터 파이프라인의 운영 흐름을 제공합니다.

Key features

Dashboard

도구별 실행 상태, DB 연결 현황, 최근 작업 결과를 모아 보고 실행 이력과 로그를 확인합니다.

Tool settings

Apache Hop, dbt, Airflow의 설치 서버와 버전을 설정하고 서비스 상태를 관리합니다.

DB connections

Source와 Target 데이터베이스 연결 정보를 등록하고 연결 테스트를 수행합니다.

Data migration

연결 쌍을 지정하고 스키마 또는 테이블 단위로 범위를 정해 생성 방식과 적재 방법을 설정합니다.

SQL transformation

연결, Source/Target 스키마와 테이블, SQL 및 쓰기 방식을 정의해 변환 작업을 관리합니다.

Job scheduling

Cron 주기 또는 선행 작업 완료 조건으로 일정을 구성하고 상태와 실행 이력을 확인합니다.

Architecture

Flask 웹 UI에서 도구와 DB 연결, 작업 정의, 스케줄을 관리합니다. 중앙 관리 API는 각 도구의 셸 스크립트나 API를 호출해 설치와 실행을 연결합니다. UI와 도구별 연동 로직을 분리해 구성 요소를 독립적으로 확장할 수 있도록 설계했습니다.
